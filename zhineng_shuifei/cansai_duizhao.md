# 赛题要求对照与补强清单

依据题目 `XH-202618 基于华为云码道（CodeArts）代码智能体解决复杂软件工程问题`，评分为完整性 50 分、应用创新性 25 分、应用真实性 25 分。统一工程已经覆盖“可运行产品”部分，但以下证据必须由参赛团队在华为云和真实场地补齐。

## 已落地的产品能力

| 赛题关注点 | 当前实现 |
| --- | --- |
| 明确复杂场景 | 面向水肥一体化机的监测、预测、决策和设备协同闭环 |
| 需求拆解 | 9 个业务页面、14 类核心数据表、20 余个拼音接口 |
| 可运行产品 | Flask 单服务，浏览器直接访问，SQLite 自动初始化 |
| 可解释决策 | 土壤湿度、EC、作物需水/需肥系数、温度、降雨概率和蒸散量共同计算 |
| 工程闭环 | 监测录入、天气预测、三日趋势、人工确认、人工操作单、执行量登记、报告与日志 |
| 质量控制 | 统一接口、异常响应、参数校验、操作留痕、可执行的接口冒烟测试 |

## 提交材料必须补齐

- **CodeArts 全流程证据**：需求分析、架构设计、Codebase 索引、研发知识问答、代码生成、单元测试生成、代码检查和部署记录。建议将每次关键操作截图、日期、输入提示词、产出文件和人工修改原因整理为 `codearts_shiyong_jilu.md`，不要只写“使用过 AI”。
- **华为云演示环境**：将本服务部署到华为云，配置持久化数据库，给出 URL、测试账号和健康检查地址；录制从监测到设备回执的完整视频。
- **真实性材料**：说明土壤数据采集方式、水肥机人工操作流程、气象数据来源和采样频率。当前内置数据仅用于本地演示，不能作为真实部署证明。
- **测试报告**：补充真实硬件断网、重复下发、传感器异常、雨天避灌、权限和压力测试的结果与截图。
- **方案 PPT**：按“痛点、需求、架构、CodeArts 过程、核心技术、测试、落地效果、扩展性”组织，避免只展示页面截图。

## 场景边界

系统输出的是“每亩建议量”和设备执行参数，不替代农艺师对品种、地块、肥料配方和安全间隔的最终确认。预测结果需要标明数据时间和来源；设备下发必须经过人工确认或明确的自动化授权。这样既符合实际工程安全，也便于答辩时说明责任边界。
